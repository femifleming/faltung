ConvoSolution - installing
==========================

macOS
  VST3/ConvoSolution.vst3            ->  ~/Library/Audio/Plug-Ins/VST3/
  VST/ConvoSolution.vst              ->  ~/Library/Audio/Plug-Ins/VST/
  Components/ConvoSolution.component ->  ~/Library/Audio/Plug-Ins/Components/
  Applications/ConvoSolution.app     ->  anywhere
  The build is not notarised. If macOS refuses to open it, run once in Terminal:
    xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/ConvoSolution.vst3
  (and the same for the other copies).

Windows
  VST3\ConvoSolution.vst3  ->  C:\Program Files\Common Files\VST3\
  VST\ConvoSolution.dll    ->  your VST2 folder (e.g. C:\Program Files\VSTPlugins\)
  Apps\ConvoSolution.exe   ->  anywhere

Linux
  vst3/ConvoSolution.vst3  ->  ~/.vst3/
  lv2/ConvoSolution.lv2    ->  ~/.lv2/
  vst/ConvoSolution.so     ->  ~/.vst/
  bin/ConvoSolution        ->  anywhere on your PATH

Impulse responses
  Eight responses are built in. For the full library download ConvoSolution-IRs.zip
  from the same release page and unpack it so that the folders (Cathedrals, Halls, ...)
  sit inside  Music/ConvoSolution  in your home folder. Your own WAV, AIFF or FLAC
  files go there too; "Folder..." in the plug-in points it somewhere else.
